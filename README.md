## The entry line

## How it works

`main.ts` (Node 22+, standard library only) writes the entry line to
`$OUTPUT_DIR/entry.txt` (default `/output`). Deterministic, no network,
no randomness.

```sh
mkdir -p out && OUTPUT_DIR=out node main.ts
```
